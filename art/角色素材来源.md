# 两套游侠预设

### 沈孤鸿的游戏模型

男主预设 `ranger` 使用 `public/assets/chars/hero-ranger-tripo.glb`。原始模型为本目录的 `78ed8fde4fc871be5c74e6be05d13419.glb`。游戏版保留原件的色彩、法线和材质贴图，将网格减到 114,000 个三角面，绑定 `man.glb` 的 65 个关节。大衣下摆的顶点通过 `_COAT_SWAY` 控制摆动，手指沿用原男主的握持骨骼。

### 原版 Blender 角色与服装

沈孤鸿的黑色旅行大衣、灰色立领内衫，以及陆青梧的青黛色斜襟短袄、盘扣和赭红腰封，使用本项目的 Blender 裁片制作。两套服装均绑定到游戏原有的 65 骨骼人物骨架。

两位角色的头颈、前臂和手使用 MakeHuman 的 hm08 人体拓扑与形态。手掌按游戏原有的腕骨、掌指和指间关节重新拟合，继续使用游戏握持动作。眉毛、陆青梧的基础辫发和两人的基础皮肤贴图来自 MakeHuman 官方系统素材。眼球依眼窝尺寸制作，虹膜和瞳孔由本项目绘制。上述 MakeHuman 资产均由原作者以 CC0 1.0 提供。原始版权方包括 Data Collection AB、Joel Palmius 与 Jonas Hauquier。

沈孤鸿现有 3D 头模的控制点保存在 `tools/shen_face_cage.csv`，肤色与发束明暗的局部色稿保存在 `art/portrait-study/`，并在构建时烘入贴图；侧分短发由项目按头型制作，侧脸深度与后脑发型由建模时推定。**注意**：若需彻底脱离原初参考照片，可在 Blender 中以 MakeHuman 原生基模重塑头型后重新导出 `hero-ranger.glb`。

皮大衣、短袄、裤子和鞋使用 Poly Haven 的实拍皮革及亚麻表面素材。服装裁片自有的褶皱叠加在实拍纹理上。原作者、素材链接和所用通道见[织物素材来源](textiles/SOURCES.md)。

### 选角立绘

选角卡使用两张 1536 × 1024 的 WebP 立绘，由内置图像生成工具按 **100% 原创虚构面孔**重新生成（不含任何现实演员或名人肖像参考）：[沈孤鸿](../public/assets/chars/portrait-ranger.webp) · [陆青梧](../public/assets/chars/portrait-xia.webp)。

- **沈孤鸿**：原创虚构 1930 年代末三十余岁冷峻游侠面孔，保留游戏原型的黑炭色宽翻领大衣、灰青立领中式内衫与盘扣、侧分微湿短发，以及 1937 沪上雨夜石库门暖灯与冷蓝侧逆光构图。
- **陆青梧**：原创虚构 1930 年代末三十岁左右干练女侠面孔，保留游戏原型的孔雀青暗纹斜襟短袄、古铜滚边与盘扣、侧分低编辫发，以及同款石库门雨夜电影感侧光构图。

### 编辑与导出

两份角色源文件均可直接用 Blender 4.5 打开，贴图已嵌入。手工修改后，在项目根目录执行对应命令，保留游戏现有 Mixamo 动画使用的骨骼本地坐标。

```powershell
blender -b "art/沈孤鸿-黑衣游侠.blend" -P tools/build_hero.py -- --preset ranger --export-only
blender -b "art/陆青梧-女侠.blend" -P tools/build_hero.py -- --preset xia --export-only
```

如需从裁片脚本重建，把上述 MakeHuman 版本中的 `base.obj`、`asian-male-young.target`、`asian-male-old.target`、`asian-female-young.target` 与 [CC0 系统素材 ZIP](https://files.makehumancommunity.org/asset_packs/makehuman_system_assets/makehuman_system_assets_cc0.zip) 放在同一源目录。在装有 Pillow 的 Blender 4.5 或 bpy 4.5 环境下调用 `tools/build_hero.py --preset ranger --makehuman-source 源目录`，另一个预设使用 `xia`。
