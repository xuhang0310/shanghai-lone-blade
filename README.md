# 沪上孤刀 · Shanghai Lone Blade (1937)

纯浏览器零下载可玩的 **1937 上海雨夜 3D 冷兵器魂系动作游戏**（Three.js + Rapier3D + Web Audio）。

## 核心玩法特色

- **纯冷兵器魂系战斗**：彻底移除热兵器，主打三连斩、八向翻滚、右键**完美弹反（Perfect Parry）**、普通格挡接左键触发《艾尔登法环》式**黄金防御反击（Guard Counter）**、架势破防后按 `[E]` **一刀绝杀**。
- **三大冷兵器绝技**：积攒刀气施放 `[1] 瞬步·居合一闪`、`[2] 破军·力劈华山`、`[3] 孤鸿·旋风乱舞`（完美弹反可缩减冷却）。
- **120m × 370m 闸北石库门雨夜大长街**：6 大推进区段、2 处侧翼暗院、3 座赐福灯龛、18 名分层递进的冷兵器敌人（长枪 / 巨斧 / 狼牙棒，4 档韧性与伤害梯度），北端设四面合围的 **`52.5m × 35m` 封闭 Boss 死斗场**与**猩红雾门**。
- **终极封闭 Boss「霸王 · 黑 龙」**：2000 血、三枚猩红绝杀印、青龙偃月重关刀、霸体韧性、55% 血量狂化震退、四大超大范围绝技。
- **严格魂系成长循环**：唯斩杀敌人与 Boss 获得战功积分；按 `[U]` 或在赐福灯龛按 `[E]` 打开**孤刀锻造强化台**升级武器锋刃、体魄血条、精力耐力与刀气修为；脱战奔跑/翻滚零耗精，初始 4 瓶 `[Q]` 金疮药。
- **电脑键鼠 + 手机横屏全端适配**：桌面端锁视角键鼠操作；移动端自动启用零遮挡紧凑 HUD、虚拟摇杆、弧形战斗键（斩击/防反、格挡/弹反、翻滚、血瓶、锁敌、上下文交互键）与三枚可点击绝技键。

## 快速运行

```bash
npm install
npm run dev
```

打开浏览器访问 `http://localhost:5173/` 即可开玩（支持局域网手机浏览器访问）。

## 测试与构建

```bash
# 运行全部 81 项自动化单元测试
node --test tests/*.test.mjs

# 生产构建
npm run build
```

## 操作指南（电脑端）

| 按键 | 功能 |
| :--- | :--- |
| `W A S D` / `Shift` | 移动 / 长按冲刺（脱战零耗精）、短按翻滚 |
| `鼠标左键` | 三连斩 / 格挡成功后按左键触发**黄金防御反击** |
| `鼠标右键` | 架刀格挡 / 迎刃瞬按触发**完美弹反** |
| `Space` / `Alt` / 双击 `A/D/S` | 八向翻滚闪避（可打断挥刀） |
| `1` / `2` / `3` | 释放三大冷兵器绝技 |
| `E` | 破防绝杀 / 赐福灯龛休整 / 穿越猩红雾门 |
| `Q` | 饮用金疮药回血 |
| `U` | 打开孤刀锻造强化台 |
| `Tab` | 锁定 / 切换敌人 |
